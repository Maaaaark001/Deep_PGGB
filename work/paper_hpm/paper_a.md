@enbody Audio measurements are routinely reported as exact numbers, yet every such number is bounded by three things: the representation of the device under test, the rounding of the analyser, and the way the estimator treats spectral leakage. We write these as a five-stage cascade - stimulus definition, input representation, engine, output representation, analyser - and adopt a single rule: a reading equals the lowest floor in the chain, so a reading at or above the analyser's own floor carries no information. Implemented in midpoint-radius ball arithmetic, the rule yields three results. First, the certificate grows at 6.0199 dB per bit of working precision, within 0.01 percent of the 6.0206 dB arithmetic ceiling; the record-length term costs 5.72 dB per doubling at N = 1024 and 6.93 dB at N = 1.41e6, so a 1.41e6-sample record at 400 bit pays 127 dB. @abs 音频测量的读数长期被当作一个确定的数，但它实际上被三层东西压住：被测对象的表示精度、分析器自身的舍入，以及估计器对泄漏的处理方式。本文把这三层写成一条五级级联——激励定义、输入表示、引擎、输出表示、分析器——并采用一条判据：读数取链中最低的那级地板，因此任何与尺子自身地板相当的读数都不携带信息。用中点—半径球算术实现后，这条判据给出三个结果。第一，证书随工作精度线性增长，斜率 6.0199 dB/bit，与 6.0206 dB/bit 的算术天花板相差 0.01%；长度项使每翻倍损失 5.72 dB（N=1024）到 6.93 dB（N=1.41×10^{6}），400 bit 下一条 1.41×10^{6} 样本的记录要付 127 dB。第二，经典的单 bin 投影把非相干记录钉在 7–33 dB，加多少位都不动，而解完整正规方程后同一段数据的地板与相干采样相同（1164.1 对 1164.2 dB）：泄漏是估计器的性质，不是数据的性质。第三，把这把尺子对准一个 binary128 重采样引擎，可证零差 440.211 dB，与级联预测相差 0.01 dB，代价是双精度引擎的 83 倍机时。全部读数附带区间证书，可由一条命令行复现。

## 1 引言

数字音频早已越过 24 bit。32 位浮点、DSD 与四精度重采样引擎都能被写出来，工程报告里随之出现 −300 dBc、−350 dBc 这样的数字。这些数字的问题是：没有人说明它们是被测对象的性质，还是分析器的性质。一个 float64 的分析链在数学上不可能给出高于 328 dB 的零差，一条 1.4×10^{6} 样本的记录在 400 bit 工作精度下光残差求和就要吃掉 127 dB——两者都不在报告的脚注里。

模拟时代的测量标准对此有明确答案。IEEE Std 1241 规定，测 ADC 要么整数周期采样（相干），要么加窗；Audio Precision 的分析仪把残余 THD+N 做到 −120 dB 量级，于是所有被测件都远远高于地板，谁也不会去问地板在哪。这条约定在数字信号处理里失效了：地板不再是模拟前端，而是浮点格式与估计器，二者都可以被推到任意远，也都可能悄悄成为读数本身。

本文处理三个具体困难。

表示。一个数存成什么格式，读数就永远被那个格式压住。把一段理想正弦舍入到 float64，读数是 328.1 dB；舍入到 binary128 是 440.2 dB；舍入到 24 bit PCM 是 140.7 dB。这三个数是格式的性质，不是信号的性质，而它们相差 300 dB。

估计器。单 bin 投影——把信号投影到一根 cos 与一根 sin 上，各自独立归一——是频谱分析的标准做法。当记录含非整数个周期时，它把能量摊到所有 bin 上，读数变成窗的形状。同一段 1000.5 Hz 的数据，单 bin 投影在 20、60、120 位十进制下恒为 71.9 dB；换成解 2×2 正规方程，同样的数据给出 6.02 dB/bit 的斜率。

尺度。证书是残差能量的上界与信号能量的下界之比。残差是 N 个平方的和，球的半径按 √N 涨，Gram 矩阵又累积 N 次舍入，于是长度不免费：N 从 1024 涨到 1.41×10^{6}，同样的工作精度要少买 66 dB。

本文的贡献是四条。

（1）五级地板级联，以及它的可证判据。读数取链中最低的一级；只有当尺子比读数高 20 dB 以上时，读数才属于被测对象。四条链的预测与实测相差 0.01 至 21 dB。

（2）证书的定量律与损耗预算。null = 6.0199·p − 4.4941·L − 0.0583·L^{2} − 10.44 dB（p 为工作精度，L = log_{2}N），最大残差 1.84 dB。三个系数分别对应算术、长度与长度的二次效应，每一项都可以独立测量。

（3）泄漏是估计器的性质。七种窗、三个精度、两种角色（权重与变换）构成一个 7×3×2 的矩阵：窗作为权重时中性，作为变换时把地板钉死。由此得到：IEEE 1241 的相干采样要求是单 bin 估计器的产物，而不是测量的必要条件。

（4）方法落地。把尺子对准一个真实的四精度重采样引擎，可证零差 440.211 dB；同一引擎的双精度版本读 307.16 dB，四精度版本慢 83 倍。

第 2 节综述相关工作并指出空白，第 3 节给出形式化与证书的定义，第 4 节是级联模型，第 5 节推导证书律与损耗预算，第 6 节处理泄漏，第 7 节是多音与互调，第 8 节把方法用于一个被测件，第 9 节讨论，第 10 节列出局限。

## 2 背景与相关工作

### 2.1 音频失真的传统刻度

THD+N、SINAD、SFDR 与 ENOB 是音频与数据转换器测试的四个基本刻度。它们的定义都以"基频能量"为分母、以"其余一切"为分子，区别只在如何切分频谱：THD+N 取全带，SINAD 取全带但把直流与基频排除，SFDR 只取最坏的一根谱线，ENOB 把 SINAD 折算成位数，SINAD = 6.02·ENOB + 1.76 dB。Kester 的应用笔记把四者的关系讲得最清楚，至今仍是工程界的通用参照。

这些刻度的隐含前提是：分析器比被测对象准。在模拟域这成立——Audio Precision 的 APx555 把残余 THD+N 做到 −120 dB 典型值，而被测的转换器很少好于 −110 dB。在数字域这条前提需要重新论证：一个 float64 的分析链在 −328 dB 处就到底了，而被测的重采样引擎可以做到 −440 dB。此时 SINAD 报出的是分析链，不是引擎。

### 2.2 相干采样与窗

IEEE Std 1241-2010 规定，ADC 频谱测试应满足相干采样，即被采样的信号在记录长度内包含整数个周期；不满足时应对数据加窗。理由是清楚的：非整数周期意味着周期延拓在记录边界上不连续，DFT 会把这份不连续摊到每一根谱线上。

Harris 1978 的窗函数综述给出了这套做法的定量依据：不同窗的主瓣宽度与旁瓣衰减、以 dB 为单位的对照表、以及"旁瓣衰减与主瓣宽度不可兼得"的取舍。Slepian 1978 的扁长球波函数（DPSS）把这套取舍推到理论极限：在给定时间—带宽积 NW 下，DPSS 是能量最集中的序列，其泄漏可以算出来，而不是量出来。

Analog Devices 的技术说明把两条路线的适用场合写成一张对照表：相干采样适合可控制的激励，窗适合不可控制的信号。这条建议在工程上是对的，但它默认了一件事——泄漏是必须压到地板以下的干扰，而不是可以写进模型的项。

### 2.3 单音参数估计

Rife 与 Boorstyn 1974 给出了离散时间单音的最大似然估计与 Cramér–Rao 下界，此后插值 FFT、相位差法、三样本线性预测等工作都在改进频率与幅度的估计精度。这些工作的目标是参数误差：频率估到 10^{-12} 还是 10^{-14}，幅度估到几个 ulp。

本文关心的是另一个量：拟合之后剩下的能量能证到多低。两者相关但不等价。一个频率估得极准的估计器仍可能因为模型里少了一项（比如直流）而把残差记高 6 dB；反过来，一个频率只估到 10^{-14} 的估计器，只要把频率误差写进证书，残差仍可证到 10^{3} dB。

### 2.4 最接近的工作

Peng 等 2022 年在非相干采样条件下恢复高精度 ADC 的频谱指标，做法是加窗加补偿，明确把相干采样当作瓶颈。这是目前与本文最接近的工作，但它仍在"窗是误差源"的框架里：目标是让窗的影响可以被扣掉，而不是让窗从模型里消失。

本文的结论方向相反：把窗放进模型（作为权重）时它是中性的，把它留在变换里时它才是地板。同一段数据、同一个精度，两种做法的读数相差 1300 dB 以上。

### 2.5 任意精度数值工具

中点—半径球算术在数学软件里已经成熟。Arb 库（Johansson 2017）用 mid-rad 表示实数，支持正确舍入的基本运算与严格包含的初等函数，代价是每个数多存一个半径；MPFR（Fousse 等 2007）提供任意精度的正确舍入浮点。IEEE 754-2019 把 binary128 定为标准格式，113 位有效位，对应 6.02×113 ≈ 680 dB 的动态范围。

这些工具被用于数论、特殊函数与可证计算，但没有被用于定义音频测量的地板。原因大概是：模拟时代的测量从不需要 300 dB，而数字时代的测量还没有人问"这个数是谁的性质"。

### 2.6 空白

据我们所知，没有工作报告过以下三件事中的任何一件：（i）把测量地板本身作为研究对象，给出它的级联结构与定量律；（ii）给音频测量读数附上可证的不确定性区间；（iii）证明相干采样是充分而非必要条件。本文给出这三件事。

## 3 形式化

### 3.1 信号模型

一段长度为 N 的实记录写成 K 个正弦加直流与残差：

@eq 1 | x[n] = d + sum_{k=1..K} ( a_{k} cos(w_{k} n) + b_{k} sin(w_{k} n) ) + e[n],   w_{k} = 2 pi f_{k} / f_{s}

其中 f_{s} 为采样率，d 为直流，e[n] 为不属于模型的全部内容——被测件的失真、量化噪声、以及任何建模遗漏。零差衡量的是 e 的能量相对于 x 的能量。

### 3.2 估计器

未知量 theta = (a_{1}, b_{1}, ..., a_{K}, b_{K}, d)，共 2K+1 个。加权最小二乘解正规方程：

@eq 2 | G theta = c,   G_{ij} = sum_{n} w[n] phi_{i}[n] phi_{j}[n],   c_{i} = sum_{n} w[n] phi_{i}[n] x[n]

phi 为基函数（cos、sin 与常数 1），w[n] 为权重。w 全为 1 时是普通最小二乘；w 取窗函数时是加权最小二乘。解出 theta 后，残差与零差为

@eq 3 | r^{2} = sum_{n} w[n] ( x[n] - xhat[n] )^{2},   x^{2} = sum_{n} w[n] x[n]^{2},   null = 10 log_{10} ( x^{2} / r^{2} )

### 3.3 证书

式 (3) 里的 r^{2} 与 x^{2} 在球算术下都不是数，而是区间 [lo, hi]。真实残差能量落在 r^{2} 的区间内，真实信号能量落在 x^{2} 的区间内，于是

@eq 4 | null >= -10 log_{10} ( hi(r^{2}) / lo(x^{2}) )

这是一个下界，而且是可以证明的下界：只要区间包含真值，式 (4) 就不可能高于真实零差。代价是它通常比"把球当中点算"得到的读数低几个 dB——低多少取决于球半径，与信号无关。

### 3.4 三个数

一次测量因此输出三个数，而不是一个。

证书（certificate）：式 (4) 给出的可证下界。

中点（midpoint）：把每个球换成它的中点后算出的零差。它收敛得快，但不保证。

尺子（ruler）：分析器在同一工作精度与同一记录长度下，对一段理想信号所能给出的最好读数。它由两件事决定——系数通道的精度与频率通道的精度，取较小者。

判据：当证书距尺子不足 20 dB 时，读数记为 ruler-limited，意思是"这个数由分析器决定，请提高工作精度"；否则记为 file-limited，意思是"这个数属于文件"。

### 3.5 为什么必须报三个

同一个文件、同一段样本、同一个分析器，工作精度取 102 位与 94 位，三个数如表 1。

@table 1 | 同一个文件、同一段样本，两种工作精度下的三个数。
| 工作精度 | 证书 | 中点 | 尺子 | 判定 |
|---:|---:|---:|---:|---|
| 102 bit | 440.189 | 440.211 | 485.6 | file-limited，距尺子 45.4 dB |
| 94 bit | 435.089 | 440.210 | 437.4 | ruler-limited，距尺子 2.3 dB |

中点的差是 0.001 dB，证书的差是 5.1 dB。掉的那 5 dB 是球半径，不是信号。没有第三列，使用者会以为这个文件只有 435 dB。

## 4 五级级联

### 4.1 结构

一条测量链有五个环节，每个环节都有自己的地板：

（1）激励定义。理想正弦在数学上是精确的，但一旦写成有限精度的样本，它就不再是正弦。用整数相位 (f·n) mod f_{s} 生成可以消除相位累积误差，但样本本身的舍入还在。

（2）输入表示。样本存成 float64、binary128 还是 PCM，决定了这一级的地板。

（3）引擎。被测对象。它的算术精度与它的算法窗共同决定它能把信号保持到什么程度。

（4）输出表示。与输入同理。

（5）分析器。估计器与它的工作精度。

读数取五者的最小值。这条规则看起来平凡，但它解释了一个长期存在的困惑：为什么两台的引擎在某些指标上读数完全一样——因为它们都贴在同一级地板上。

表 2 前两行的实测比地板低 21 dB，原因不是尺子不准，而是被测对象本身在那一级之上就已经失败了：一段由 float64 引擎产生的输出，其误差（307 dB）低于 float64 的表示地板（328 dB）——引擎的舍入与信号的舍入是同一件事，读数落在两者之中较低的那个上。后两行的实测与地板相等，说明此时引擎的误差已经低于输出的表示地板，读数由格式决定。

这条规则有一个直接后果：报告一个读数时必须同时报告它所在级的地板。否则 −300 dBc 这样的数字在 float64 分析链上无法与 −328 dB 区分。

### 4.3 整数周期的陷阱

零差估计要求分析段包含整数个周期，否则投影读到的是矩形窗的泄漏裙边。这一点在 float64 时代不显眼——地板本来就在 300 dB，泄漏裙边在 260 dB 以下，压不到读数。在 440 dB 的时代它会直接毁掉实验。

一段 4 秒的记录，跳过前 5% 后剩 3.6 秒。当 f_{s} = 88200、f = 997 Hz 时，3.6 秒含 3589.2 个周期，不是整数。此时 997、1499、2003、2503、7001 Hz 全部读到 262–298 dB，而 1000 与 5000 Hz 读到 437 dB——两种精度读到同一个错误值，看起来像"引擎在低频更差"。

修法是把跳过长度与分析长度都对齐到 f_{s}/gcd(f, f_{s}) 的整数倍。修好之后尺子自检从 298 dB 回到 689.8 dB。

## 5 证书律与损耗预算

### 5.1 律

在 26 个测量点上（p = 60…960 bit，N = 1024…1.41×10^{6}，f = 1 kHz，精确整数相位基，零保护位）拟合：

@eq 5 | null = 6.0199 p - 4.4941 L - 0.0583 L^{2} - 10.44   [dB],   L = log_{2} N

最大残差 1.84 dB，均方根残差 0.71 dB。线性形式（只保留 −5.79·L）在同一批点上留 2.42 dB 残差，因此取二次。尺子律（式 6）形状相同，恒高 3.0 dB：

@eq 6 | ruler = 6.0199 p - 4.4580 L - 0.0593 L^{2} - 13.76   [dB]

把尺子扫描与顾问验证的另外 36 个点合进来重拟合（共 62 点），得到 6.0209·p − 4.4849·L − 0.0541·L^{2} − 12.10（最大残差 2.58 dB，均方根 1.21 dB），与式 (5) 在 400 bit、N = 1024…1.41×10^{6} 上相差不超过 0.8 dB。律是稳的；保留 26 点版本是因为它只用了同一条流水线产出的数据。

@fig fig2_law.png | 597x477 | 图 2 | 证书律及其三项代价。(a) 四个记录长度的证书随工作精度线性增长，虚线为 6.0206 dB/bit 的算术天花板；四条曲线几乎重合，因为长度项只占几个百分点。(b) 400 bit 下，长度项、二次项与常数项各自吃掉多少 dB：N 从 1024 到 1.41×10^{6}，总损失从 61 dB 涨到 127 dB。(c) 每翻倍损失本身随 N 增长，从 5.72 dB 到 6.93 dB——这是二次项的导数。(d) 外推验证：在 1.27×10^{6}、2.82×10^{6}、5.64×10^{6} 三个长度上，实测一律高于律的预测（即律偏保守），残差随精度升到 6.8 dB。

### 5.2 三个系数分别是什么

6.0199 dB/bit 是算术天花板 6.0206 的 0.01%。一位工作精度换一位证书，没有别的项能换到这么多。

−4.49·L − 0.058·L^{2} 是长度的代价。残差是 N 个平方的和，球的半径按 √N 涨而信号能量按 N 涨，这一项本身只值 3 dB/倍；Gram 矩阵累积 N 次舍入再叠一层。二次项说的是第二层在放大：每翻倍损失在 N = 1024 时是 5.72 dB，N = 1.41×10^{6} 时是 6.93 dB，而这条曲线的斜率正是二次项的导数。

−0.184 dB/十倍频（在式 (5) 中被并入常数项）几乎为零，前提是基函数用精确整数相位计算。用 cos(w·i) 直接算时同一项是 −2.1，在 4 kHz 处白丢 15 dB；那不是测量的性质，是参数约化的性质。精确相位把每个样本的相位约化到 [0, 2 pi)，半径因此与 i 无关（实测恒为 16 个 eps 量级），在 100、1000、3990 Hz 上分别多买到 1.9、12.8、20.7 dB。

### 5.4 恒定的 3 dB 缺口

证书用系数通道的三角不等式 |dm| ≤ rad(a) + rad(b)，两个半径相加让幅度多算 √2，功率上正好 +3.01 dB。20 个尺子点实测 3.01–3.08 dB（均值 3.03），每个 (p, N) 都是 +3.0。改成正交式 (ra^{2} + rb^{2})/2 能复现证书到 0.05 dB，但它不是上界，所以工具里保留三角不等式，把这 3 dB 当作诚实的代价。
