## 6 泄漏是估计器的性质

### 6.1 一个 7×3×2 的矩阵

把"加窗"拆成两个互不相同的动作。

窗作为变换：先乘窗再投影到单根 cos/sin 上，用闭式解 a = <w·x, cos>/<cos, cos>、b = <w·x, sin>/<sin, sin>。这是频谱分析的常规做法。

窗作为权重：把 w[n] 写进式 (2) 的权重，解加权正规方程。窗在这里不改变被估计的量，只改变每个样本的话语权。

两种角色各扫七种窗（矩形、Hann、Hamming、Blackman、Blackman–Harris、flat-top、Nuttall）与三个精度（60、240、480 bit），数据是同一段非相干记录：1000.5 Hz，f_{s} = 8 kHz，N = 4096。

@fig fig3_window.png | 597x237 | 图 3 | 窗的双重身份。(a) 窗作为权重：七种窗的证书曲线几乎重合，精度每翻倍涨 6.02 dB，窗的选择只造成不到 2 dB 的差别。(b) 窗作为变换：同一段数据、同一组窗，读数恒为 7.0 至 32.8 dB，从 60 bit 加到 480 bit 一动不动。(c) DPSS 的泄漏上界，由核矩阵的 Rayleigh 商给出严格界；NW 从 2 到 8，上界从 −42 dB 走到 −204 dB，且几乎与记录长度无关。

### 6.2 为什么

单 bin 投影隐含地假设 cos 与 sin 在记录上正交，即 <cos, sin> = 0、<cos, cos> = <sin, sin> = N/2。非整数周期时这个假设不成立：<cos, sin> 不为零，两个系数互相污染，残差里留下一个与窗形状成正比的项。这个项不随精度缩小，因为它是代数误差，不是舍入误差。

解完整正规方程时，污染被显式消掉——G 的非对角元被求逆吸收。剩下的只有舍入，而舍入随精度下降。

于是"泄漏"这个词指两件不同的事：一是数据在边界上的不连续（真实存在，属于信号），二是估计器把这份不连续错误地归因于模型（属于算法）。前者无法消除，后者可以。

### 6.3 对 IEEE 1241 的含义

IEEE 1241 要求相干采样，否则加窗。上面的矩阵说明这条要求是单 bin 估计器的产物：在最小二乘框架下，非相干数据的证书与相干数据相同（同一段 1000.5 Hz 的数据读到 1164.1 dB，1 kHz 的相干数据读到 1164.2 dB，差 0.1 dB），而窗只是权重，加不加都一样。

这不意味着相干采样没有价值。整数周期让 FFT 的 bin 与信号严格对齐，使频谱图可以直接读，使单次 FFT 就能给出幅度，使实时分析成为可能。它的价值是工程上的，不是测量精度上的。把两者混为一谈，代价是在必须非相干（比如自由运行的振荡器、无法同步的播放链路）时误以为精度已经到顶。

### 6.4 未知频率

若频率也未知，先用三样本线性预测给出初值，再用高斯–牛顿同时解幅度与频率：

@eq 8 | w_{0} = arccos( ( x[n] + x[n+2] ) / ( 2 x[n+1] ) )

式 (8) 给出的初值在 600 bit、N = 4096 上，对 1000.5、1234.567、1999.37 Hz 三个频点的相对频率误差分别是 2.2×10^{-198}、1.5×10^{-198}、1.4×10^{-198}，证书分别为 3403.9、3403.0、3399.6 dB。

代价在证书上：每一次牛顿迭代把球半径放大约 17.5 倍，证书每步掉 24.8 dB。中点在收敛，区间在变宽。这是三参数正规方程的条件数造成的，不是实现的缺陷。两条对策：一是加保护位，但实测无效（见 8.5）；二是把频率的不确定度写成 Lipschitz 项而不是区间项：

@eq 9 | null >= -10 log_{10} ( 2 dw^{2} sum_{n} n^{2} / N )

其中 dw 是频率的绝对不确定度。它的来历是一行代数：频率偏差 dw 使模型在第 n 个样本上偏离约 A·dw·n，残差能量因此是 A^{2}dw^{2}sum n^{2}，而信号能量是 A^{2}N/2，两者之比即式 (9) 括号里的量。在 N = 4096、400 bit 上，把频率相对扰动从 10^{-10} 推到 10^{-90}，实测零差与式 (9) 的差恒为 9.0 dB（实测 140.6、340.6、…、1740.6，界 131.6、331.6、…、1731.6）。这个界是闭式的、便宜的、紧的，而且不随迭代次数恶化。

## 7 多音与互调

### 7.1 解析基准

四音激励，频率 1001、6997、13003、18997 Hz，幅度 0.20、0.15、0.10、0.05（不等幅是刻意的：等幅会让多个产物重合在同一电平上，从而掩盖枚举错误）。被测件是已知的三次非线性 y = x + a_{3} x^{3}，a_{3} 取 10^{-3}、10^{-5}、10^{-7}。

三次非线性的产物频率是三个带符号频率之和 f = s_{1}f_{1} + s_{2}f_{2} + s_{3}f_{3}，s_{i} 取 −1、0 或 +1，且恰有三个非零。复幅度

@eq 10 | C(f) = ( 3 a_{3} / 4 ) sum A_{i} A_{j} A_{k} exp( i ( phi_{i} + phi_{j} + phi_{k} ) )

对每个满足 f_{i} + f_{j} + f_{k} = f 的有序三元组求和，实信号的物理幅度是 2|C(f)|。

三个容易出错的地方都在这里。其一，必须枚举带符号的有序三元组，否则 2f_{1} − f_{2} 这类需要负系数的产物不可达。其二，x^{3} 是实信号，C(−f) = conj(C(f))，正负频率各贡献一半，漏掉因子 2 会让整张表低 6.02 dB。其三，折叠到同一个 bin 的多个别名必须先按复数相加再取模：相位相反的别名会抵消，而按幅度相加会把这一根 bin 读高。

排序本身是电平差的来源：2f_{1} − f_{2} 有三个排列贡献，读 3a_{3}A_{1}^{2}A_{2}/4；3f_{1} 只有一个排列，读 a_{3}A_{1}^{3}/4。

第三条在第一版实现里被漏掉，代价是一个具体的数字。2f_{3} + f_{4} = 45 003 Hz 与 f_{2} + 2f_{3} = 50 997 Hz 都折叠到 2 997 Hz，两者幅度相同、相位相反，复数和为零，实测 −120.56 dBc；按幅度相加的预测给 −111.02 dBc，差 9.54 dB。同一个错误在 8 991 Hz 上差 2.18 dB。表里 58 个产物中只有这两根 bin 受影响，所以它看起来像"个别点偏了半个 dB"，而不是像系统错误——这类错误只有在同时打印预测与实测时才暴露。

### 8.4 模型必须包含直流

第一次做这张表时 PCM 24 读 134.332 dB，比理论值低 6.3 dB。逐项查下来：式 (1) 的 d 项没有被放进模型：正规方程只有 cos 与 sin 两列，没有常数项。这段合成正弦的样本均值是 −5.947×10^{-8}，占残差能量的 76.7%；它被当成"零差"记了账。

把直流作为第 2K+1 个未知量加进正规方程后，同一文件读 140.662 dB，与 numpy 最小二乘逐位一致，也与理论值对上。

任何"残差等于数据减模型"的证书，模型漏一项就等于给被测对象减分。直流是最容易漏的一项，因为它看起来不像信号。

### 8.5 保护位为什么无效

直觉上，多留几十位保护位应当提高证书。实测（N = 4096，240 bit 工作精度）恰好相反，见表 11。

@table 11 | 保护位对证书的影响，N = 4096，240 bit。
| 保护位 | 0 | 16 | 32 | 64 | 128 | 256 |
|---|---:|---:|---:|---:|---:|---:|
| 证书与中点的差 (dB) | +72.34 | −22.66 | −118.99 | −311.65 | −688.39 | −691.68 |

保护位超过 64 之后，证书反而比中点高出数百 dB，即式 (4) 变成一句废话。原因是激励本身只精确到 240 bit：当分析器比激励准得多时，残差的区间宽度由激励的舍入决定，而不是由分析器决定。多给保护位只会让分析器更精确地看见激励的误差。

这条实验解释了为什么精度顾问必须反向拟合（给定目标求精度），而不能正向拟合（给定精度求目标）：正向拟合在低精度端受激励限制，在高精度端受长度限制，两端的机制不同。

## 9 讨论

### 9.1 相干采样是充分条件

第 6 节的结果可以写成一句更强的话：整数周期采样是得到正确频谱的充分条件，不是必要条件。最小二乘框架下，非相干数据的证书与相干数据相同；窗作为权重是中性的；只有把窗留在变换里、用单 bin 投影时，非相干才成为问题。

这条结论的实际价值在于：自由运行的振荡器、无法同步的播放链路、实时采集的片段，都不必先想办法凑整数周期。代价是必须解正规方程而不是投影一次，以及必须知道频率（或用 6.4 节的牛顿法）。

### 9.3 什么时候值得

精度不是免费的，也不是普遍有用的。三条判据：

（i）被测件的读数已经贴到分析链的地板。float64 分析链在 328 dB，若被测件读到 300 dB，加精度只会在 328 dB 处停住——先换输出格式。

（ii）问题本身要求这个量级。判断一个重采样引擎在 −300 dBc 处的行为，用 float64 分析链是可以的；判断它在 −440 dB 处的行为，必须整条链换。

（iii）比较必须在同一级上。两台引擎都读到 307 dB 时，它们可能都贴在地板上，此时的排序是噪声。第 4.2 节的表就是为了让这种情形一眼可见。

### 9.4 一个可操作的判据

把上面三条写成一条命令行可执行的过程，见表 14。

@table 14 | 一条可执行的判据。
| 步骤 | 操作 | 判据 |
|---|---|---|
| 1 | 读文件，取默认精度 | 得到证书与尺子 |
| 2 | 若证书距尺子不足 20 dB | 提高精度，重做 |
| 3 | 若提高精度后证书不再增长 | 饱和，报中点 |
| 4 | 若中点仍低于该格式的表示极限 | 模型缺项（直流、谐波、频率） |
| 5 | 报三个数：证书、中点、尺子 | 缺一不可 |

第 4 步是 8.4 节的教训：饱和之后仍低于理论值，问题不在精度，在模型。

## 10 局限

（1）长度。证书律在 1.27×10^{6} 至 5.64×10^{6} 样本上验证过外推，更长的记录（例如整张专辑的连续分析）没有测。

（2）模型。本文的模型是"K 个正弦加直流"。谐波、互调、噪声底、抖动都不在模型里，它们会被计入零差——这在测失真是对的，在测噪声时会把噪声读成失真。

（3）频率。未知频率的处理依赖三样本线性预测给出初值。当信号含强谐波时，线性预测的初值误差可达 2.5×10^{-6}，牛顿法能把它推到 1.7×10^{-14}，但证书随之掉到 120 dB（等于谐波本身的电平）。这是正确的行为，不是缺陷，但它意味着"未知频率加含谐波"这个组合的证书上限由谐波决定。

（4）单通道、单次实现。所有实验都是单通道；每个读数来自一条记录的一次实现。证书对给定文件是确定的，但文件本身是一个 realization，跨实现的散布本文没有统计。多通道的联合估计（共享频率、独立幅度）可以把频率的不确定度摊到更多样本上，也没有做。

（5）实现。球算术的墙钟是仿射的，固定项（解码与三角函数）在低精度端占 82%。用查表或递推的相量可以把这一项压下去，本文没有优化。

（6）比较对象。商业音频分析仪的模拟前端在 −120 dB 量级，本文的方法在数字域，两者不构成同一层面的比较。本文的意义不是"比 APx555 好 320 dB"，而是"当被测对象进入数字域的深处时，需要一个不同性质的尺子"。

## 11 结论

测量读数不是一个数。它是三个数：一个可证的下界、一个收敛的中点、以及尺子自身的地板。把这三件事一起报出来，读数才有意义。

在这个框架下，音频测量的地板可以被定量地写出来：证书随工作精度以 6.0199 dB/bit 增长，与算术天花板相差 0.01%；长度每翻倍吃掉 5.72 至 6.93 dB，一条 1.41×10^{6} 样本的记录在 400 bit 下要付 127 dB。

同样在这个框架下，两个长期被当作物理事实的东西显出它们的真实身份。泄漏是估计器的性质：同一段非相干数据，单 bin 投影在 7 至 33 dB 之间不动，完整正规方程给出 6.02 dB/bit 的斜率。相干采样是充分条件而不是必要条件。

把这把尺子对准一个真实的四精度重采样引擎，可证零差 440.211 dB，与级联模型的预测相差 0.01 dB，代价是 83 倍机时。这个数字的意义不在于它有多大，而在于它是可证的、可复现的、并且明确地属于被测对象。
