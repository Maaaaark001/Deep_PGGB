## 5 证书律与精度预算

### 5.1 律的形状

第 4 节把读数归给某一级，但没有回答一个实际问题：给定目标，需要多少位、多长的记录、多少机时。这三件事由一条经验律给出。

在 26 个尺子点上（工作精度 60 至 960 bit，记录长度 1024 至 1.27×10^{6} 样本，1 kHz 单音，整数相位基，零保护位）拟合，证书服从

@eq 7 | null = 6.0199 p - 4.4941 L - 0.0583 L^{2} - 10.44,   L = log_{2} N

最大残差 1.86 dB，均方根 0.71 dB，残差范围 −0.87 至 +1.86 dB。用另一组 36 个点重拟合，四个系数变化不超过 0.8 dB，形状不变，这排除了「系数是某组数据的偶然产物」。线性拟合（去掉 L^{2} 项）在整个区间上留 2.4 dB 残差，二次拟合留 1.8 dB，因此二次项是必要的。

三个系数各自对应一个可以独立测量的机制。

6.0199 dB/bit 是算术。一个二进制位的精度换 6.0206 dB 的动态范围，实测斜率与之相差 0.01%。这一项与记录长度、频率、信号形状都无关，它是球算术本身的刻度。

−4.4941·L 是长度。残差是 N 个平方的和，球的半径按 √N 增长，而信号能量按 N 增长，单这一项就要 3 dB/翻倍；系数的半径也随 N 增长（Gram 矩阵累积 N 次舍入），实测斜率因此是 4.49 dB/翻倍。这一项的来源可以用两种基函数分开验证：用 cos(w·i) 直接算相位时，斜率是 −5.79 dB/翻倍、常数 −4.22；用整数相位规约（2π·((f·i) mod f_{s})/f_{s}）时斜率降到 −4.49、常数 −10.44。两式的斜率差 1.3 dB/翻倍，常数差 6.2 dB，合起来在 N = 1024 至 65 536 上只差 0.1 至 1.5 dB——差的是预算在长度项与常数之间的分配，不是总量。斜率差本身来自相位规约的误差：cos(w·i) 先乘后约化，误差随 i 增长，长度越长付得越多。这解释了为什么所有实验都用整数相位基。

−0.0583·L^{2} 是长度的二次效应。每翻倍的代价本身随 N 增长：N = 1024 时 5.72 dB，N = 1.41×10^{6} 时 6.93 dB（图 2c）。二次项的意义是：长记录的代价不只是「多」，而且「越来越贵」。

### 5.3 律的外推边界

式 (7) 在拟合区间之外是外推。七个外推点全部高于律的预测，即律偏保守（图 2d）。工作精度 960、1920、3840 bit 在 1.27×10^{6} 样本上高出 +1.85、+2.52、+6.79 dB；240 与 480 bit 在 2.82×10^{6} 样本上高出 +4.38、+2.45 dB，在 5.64×10^{6} 样本上高出 +5.39、+3.46 dB。

残差随精度增长到 6.8 dB，这是律只能当规划工具、不能当上界的理由。偏保守的方向是可接受的：用它规划会多买一些精度，不会少买。

## 6 泄漏是估计器的性质

### 6.1 两种角色

「加窗」在工程实践里是一个动作，在数学上是两个互不相同的动作，把两者分开是本节的关键。

窗作为变换：先乘窗再投影到单根余弦与单根正弦上，用闭式 a = ⟨w·x, cos⟩/⟨cos, cos⟩、b = ⟨w·x, sin⟩/⟨sin, sin⟩。这是频谱分析的常规做法，窗在这里改变了被投影的量。

窗作为权重：把 w[n] 写进式 (2) 的权重，解加权正规方程。窗在这里不改变被估计的量，只改变每个样本的话语权。

两种角色各扫七种窗（矩形、Hann、Hamming、Blackman、Blackman–Harris、flat-top、Nuttall）与七种工作精度（60、90、120、180、240、360、480 bit），数据是同一段非相干记录：1000.5 Hz，f_{s} = 8 kHz，N = 4096。共 49 个读数，结果见图 3 与表 6。

### 6.2 闭式

单 bin 投影的地板可以算出来，不需要量。设归一化窗变换为式 (9)：

@eq 9 | L( w ) = ( 1 / sum_{n} w[n] ) sum_{n} w[n] exp( -i n w )

单 bin 估计把音投影到一根余弦与一根正弦上，两者在非整数周期下并不正交，于是音的「镜像」（频率 −f，等价于把相位写成 2ω_{0}n 的形式）没有被消掉，而是按 L(2ω_{0}) 的比例留在残差里。残差能量因此是 A^{2}|L|^{2}/2，信号能量是 A^{2}/2，地板为

@eq 10 | null_{sb} = -20 log_{10} | L( 2 w_{0} ) |

式 (10) 只依赖窗的形状与音在记录中的位置（即 ω_{0} 与 N 的小数部分），不依赖工作精度，也不依赖信号的幅度。表 6 的最后一列是式 (10) 在 1200 bit 下的取值，与实测列逐行相等，49 个点的最大偏差 0.011 dB。

式 (10) 的实用价值在于它是一个设计公式：选窗之前就能算出这个窗在这个音上会把地板压到哪里，不必先跑一次测量。它的理论价值在于它把「泄漏」定性了——泄漏不是数据在边界上的不连续被 DFT 摊开，而是估计器用一个不适定的投影把音的一部分误记成残差。

### 6.3 窗作为权重是中性的

同一段数据、同一组窗，只要解式 (2) 而不是做单 bin 投影，泄漏就消失了：七种窗在 60 bit 下相差 2.11 dB，在 480 bit 下相差 2.12 dB，且这个差与精度无关。它不是泄漏，而是加权改变了有效样本数与 Gram 矩阵的条件数——同一个 2.1 dB 在 60 bit 与 480 bit 上重复出现，正说明它与舍入无关。精度从 60 加到 480，读数从 287 dB 涨到 2815 dB，斜率与无窗时相同。

窗作为权重时中性，这一点可以用 DPSS 独立验证。DPSS 是在给定时间—带宽积 NW 下能量最集中的序列，它的泄漏上界由核矩阵的 Rayleigh 商给出，是严格界而不是测量值（图 3c）：NW 从 2 到 8，上界从 −42.4 dB 走到 −202.9 dB，N 从 128 到 1024 变化时上界几乎不动（−42.44 到 −42.42 dB）。用 NW = 4 的 DPSS 作权重，N = 512、400 bit 下的证书是 1136.97 dB，无窗时是 1136.93 dB，相差 0.04 dB。

DPSS 是「最好的窗」，而它作权重时的读数与无窗相同。这条对照说明：在最小二乘框架下，窗的选择不影响地板，因为窗不改变模型，只改变每个样本的权重；地板由精度与长度决定。

### 6.4 相干采样是充分条件

把 6.3 节的结论写成一句更强的话：整数周期采样是得到正确频谱的充分条件，不是必要条件。

直接对照：同一段非相干数据（1000.5 Hz）与相干数据（1000 Hz、1001 Hz、1234.5 Hz），在 200 bit、N = 4096、f_{s} = 8 kHz、无窗、解完整正规方程的条件下，证书分别是 1118.72、1119.64、1118.74、1117.90 dB。四个数落在 1.74 dB 的范围内，而同一组数据在 480 bit 下是 2804.49、2805.44、2804.51 dB。非相干与相干之间的差别小于 2 dB，与工作精度带来的 1685 dB 相比可以忽略。

这条结论的实际价值在于：自由运行的振荡器、无法同步的播放链路、实时采集的片段，都不必先想办法凑整数周期。代价是必须解正规方程而不是投影一次，以及必须知道频率（或用 3.3 节的牛顿法）。

它不意味着相干采样没有价值。整数周期让 FFT 的 bin 与信号严格对齐，使频谱图可以直接读，使单次 FFT 就能给出幅度，使实时分析成为可能。它的价值是工程上的，不是测量精度上的。把两者混为一谈，代价是在必须非相干时误以为精度已经到顶。

### 6.5 未知频率

频率未知时，先用式 (5) 的三样本线性预测给初值，再用高斯–牛顿同时解幅度与频率。600 bit、N = 4096 下，对 1000.5、1234.567、1999.37 Hz 三个频点，初值的相对误差分别是 2.2×10^{-198}、1.5×10^{-198}、1.4×10^{-198}，牛顿收敛后的证书分别是 3403.9、3403.0、3399.6 dB，频率的相对不确定度约 1.5×10^{-174}。

代价写在证书上：每一次牛顿迭代把球半径放大约 35 倍，证书每步掉 30 dB。中点在收敛，区间在变宽。这是三参数正规方程的条件数造成的，不是实现的缺陷。

两条对策。一是加保护位，见 6.6 节，它其实有效，但有效的方式与直觉相反。二是把频率的不确定度写成 Lipschitz 项而不是区间项，即式 (6)。式 (6) 在 N = 4096、400 bit 上，把频率相对扰动从 10^{-10} 推到 10^{-90}，实测零差与界的差恒为 9.03 dB（实测 140.64 至 1740.64 dB，界 131.61 至 1731.61 dB）。这个界是闭式的、便宜的、紧的，而且不随迭代次数恶化。

### 6.6 保护位：两个上限，不是一个

保护位（guard bits）指求解与残差求值比名义工作精度多给的位数。直觉上多给保护位应当提高证书；早期的实现把它记成「无效」，理由是实测证书在中点之上几百 dB，式 (3) 变成一句废话。这个记录是错的，错在把保护位排除在横坐标之外。

保护位属于算术，因此横坐标应当是有效精度 p_{eff} = p + guard。以 p_{eff} 为横坐标重画（图 4a），四条曲线的形状完全一致：证书沿式 (7) 上升，直到撞上一个平台。平台的高度只由激励精度 p_{stim} 决定，与记录长度无关（图 4b）：

@eq 11 | null_{cap} = 6.0199 p_{stim} - 30.5

p_{stim} = 120、240、360、480 bit 时，平台分别是 691.59、1414.44、2136.62、2859.05 dB，式 (11) 的预测是 691.89、1414.28、2136.66、2859.05 dB，差 0.30、0.16、0.04、0.01 dB（表 7）。N = 1024 与 N = 4096 给出同一组平台（相差 0.00 dB），因此式 (11) 里没有长度项。

式 (11) 的常数 −30.5 dB 比式 (7) 的 −10.44 dB 多 20 dB，这个差可以拆成两个可测的部分，不必当成拟合出来的黑箱。

第一部分是激励本身的舍入。合成激励在 p_{stim} 上用整数相位算正弦，每个样本带 2^{-pstim} 量级的舍入；把这些样本的中点在 p_{stim}+400 bit 的基上重新拟合，残差中点的均方根是 1.033×2^{-pstim}（p_{stim} = 120）与 0.384×2^{-pstim}（p_{stim} = 240），比均匀量化的 q/√12 高 0.29 dB 与低 8.31 dB。这一项直接进入中点：残差中点的零差是 713.16 与 1444.22 dB，而理想量化地板 1.7609 + 6.0206 p_{stim} 是 724.23 与 1446.70 dB。偏差的符号与大小随精度翻转，来源是正弦的相位分布并不均匀，量化误差的均方根因此偏离 q/√12。

第二部分是 Arb 对残差平方和的包络。残差 r^{2} 是一个球，它的半径与中点之比在 p_{stim} = 120 时是 1.10×10^{2}（20.41 dB），在 p_{stim} = 240 时是 3.50×10^{2}（25.44 dB）；系数 a、b 的半径只有 10^{-36} 量级，可以忽略。于是证书比中点低 18.84 与 26.81 dB。

两部分相加，p_{stim} = 120 时是 ( 11.07 − 0.29 ) + 18.84 = 29.62 dB，p_{stim} = 240 时是 ( 2.48 + 8.31 ) + 26.81 = 37.60 dB。前者与式 (11) 的 30.5 dB 相差 0.9 dB，后者相差 7.1 dB。因此 −30.5 dB 是一个在 120 至 480 bit 之间稳定的经验截距，不是两个常数项的简单相加；两项的相对大小随精度此消彼长，截距的稳定性来自这种抵消，而不是来自每一项都不变。

两个上限的物理含义不同，这是本节的重点。式 (7) 是估计器的上限：它随记录长度下降，因为 Gram 矩阵累积 N 次舍入。式 (11) 是文件的上限：它与记录长度无关，因为激励的每个样本都带同样大小的表示误差。测量的读数是两者的最小值：

@eq 12 | null_{read} = min( null_{est}( p + guard, N ), null_{cap}( p_{stim} ) )

@fig fig4_guard.png | 图 4 | 保护位与两个上限。(a) 以有效精度 p_{eff} = p + guard 为横坐标，四条曲线沿式 (7) 上升后各自撞上平台；平台高度只由激励精度决定。(b) 平台对激励精度是斜率 6.0199 dB/bit 的直线，截距 −30.5 dB；记录长度 1024 与 4096 给出同一条线（为避免两点完全重合，横坐标加了 ±3.2 bit 的偏移）。

式 (12) 解释了保护位为什么「看起来无效」：在早期实验里 p_{stim} = 240 bit、p = 240 bit，保护位一加，估计器上限立刻升到 2136 dB，而文件上限只有 1414 dB，于是读数停在 1414 dB 不动，再加保护位也不动。旧记录把这个平台读成「式 (3) 失效」，实际上它是文件的性质——与第 8 节的表示阶梯（binary128 689.5、float64 328.3、PCM 24 140.2 dB）是同一类数，只不过那三级的格式是存储格式，这里的格式是激励的生成精度。

由此得到一条实用的操作规则：保护位不是「多给一点更保险」，而是「把估计器挪开，让文件的上限露出来」。给定激励精度，保护位取到 p + guard > p_{stim} 即可，再多无益；反过来，若想看到更深的读数，必须提高激励精度，而不是提高工作精度。

这条规则与第 8 节的饱和扫描形状相同而机制不同，两者不要混。8.4 节那个 binary128 文件在 140 bit 处贴住 665.522 dB，那不是激励精度造成的平台：激励精度远高于此，文件格式的地板是 689.56 dB，665.522 dB 是引擎自己的误差。一个是「文件装不下」，一个是「被测件做不好」，判据第 4 步就是为区分这两者而设的。

## 7 多音与互调

### 7.1 为什么要整表

单音只检验一个频率上的残差。多音检验的是模型能不能把 K 根音与它们的全部产物分开，这在任意精度下是一个苛刻的要求：产物可能比基频低 170 dB，而残差地板在 300 bit 上是 1700 dB，两者相差三个数量级，任何一个环节的漏项都会让整表错位而不报错。

四根音取 1001、6997、13003、18997 Hz，幅度 0.20、0.15、0.10、0.05，f_{s} = 48 kHz，N = 48000，信号通过已知的三次非线性 y = x + a_{3}x^{3}，a_{3} 取 10^{-3}、10^{-5}、10^{-7}。幅度刻意不等：等幅会让许多产物重合在同一电平上，掩盖枚举错误。

### 7.2 解析式与两个必踩的坑

三次项产生的谱线由带符号的有序三元组枚举。把每根音写成复指数之和，x^{3} 在频率 f 上的复系数是

@eq 13 | C( f ) = a_{3} sum_{triples} prod_{k} ( A_{k} / 2 ) exp( i s_{k} phi_{k} ),   sum_{k} s_{k} f_{k} = f

x^{3} 是实信号，因此 C(−f) = conj(C(f))，正负两根谱线同相相加，频率 f 上的物理幅度是 2|C(f)|。两个因子都不可省：漏掉符号，2f_{1} − f_{2} 这类需要负频率的产物根本不可达，读数变成 −inf；漏掉因子 2，整表低 6.02 dB。

第三个坑在别名上。f_{s} = 48 kHz 时，2f_{3} + f_{4} = 45003 Hz 与 f_{2} + 2f_{3} = 50997 Hz 都折叠到 2997 Hz，而它们的相位相反：前者三个排列给出 |c| = 6.25×10^{-5}、相位 −90°，后者三个排列给出 |c| = 3.125×10^{-5}、相位 +90°。按复相量相加得 9.375×10^{-5}，按幅度相加得 2.8125×10^{-4}，两者差 9.54 dB。8991 Hz 上的 −3f_{3} 同样是两项相加，差 2.18 dB。这就是式 (13) 必须按复相量折叠、不能按幅度叠加的原因。

## 8 把尺子对准被测件

### 8.1 被测件与尺子

被测件是一个四精度的重采样引擎：44.1 kHz 到 88.2 kHz，16 秒 1 kHz 正弦，输出写成 binary128，共 1 411 200 个样本。binary128 的每个值都是二进制有理数，Arb 可以精确表示，因此残差里没有「读文件」这一项误差，读数属于引擎。

分析用 400 bit，跳过首尾各 0.8 秒（引擎在块边界上有 20 ms 的渐变）。尺子 2 279.7 dB，证书 665.522 dB，两者相等，残差平方和的球在 400 bit 下已经收成一个点。

### 8.2 读数与三个差值

引擎的读数与三个参照各差一截，三个差值说明三件不同的事。

比律的预测高 226 dB，这个比较需要说清楚它比的是什么。式 (7) 描述的是估计器在 p bit 下的能力：把 p = 94 代进去得 439.29 dB，正好是旧读数的位置；要在 665 dB 处生效，律要求 p = 132 bit。而引擎的算术只有 113 bit。换句话说，665.52 dB 这个读数已经比引擎的算术精度所对应的估计器地板深 19 bit——它是靠 400 bit 的尺子才被证出来的，律在这里没有预测力，因为律描述的是「估计器不够好」的那一侧，而这里限制读数的是被测件。

比输出格式的地板低 24.0 dB。binary128 在同一长度、同一频率上的格式地板是 689.56 dB（第 8.3 节），引擎做到 665.52 dB。这 24 dB 是引擎的误差，不是存储的误差——把同一段合成激励写成 binary128 能读到 689.45 dB，说明格式本身装得下。

比尺子低 1 614 dB。尺子 2 279.7 dB 与读数 665.522 dB 之间还有 1 614 dB 的余量，因此这个读数与仪器无关。判据第 1 步不触发。

残差均方根 1.87×10^{-34}，拟合幅度 0.49999999999999994，与真值 0.5 相差 6×10^{-17}。作为对照，binary128 在 0.5 附近的间距是 2^{-113} = 9.6×10^{-35}（略小于 0.5 时 4.8×10^{-35}）：残差均方根约等于两个间距，已经落到表示本身的量级；而幅度误差 6×10^{-17} 仍比间距高 18 个数量级。这两件事不矛盾——幅度是整段记录上的平均，一个恒定的相对缩放不会增加残差的均方根，只会让拟合系数偏离 0.5。

### 8.3 表示阶梯

要判断 665.52 dB 属于格式还是属于引擎，需要先知道格式本身能读到多深。做法是在 1200 bit 上合成一段理想正弦，再舍入成五种格式，用 600 bit 的尺子去读（该长度下尺子 3 511.7 dB）。

频率必须取 1001 Hz 而不是 1000 Hz。1000 Hz 在 8 kHz 采样下每个周期只访问 8 个不同相位，量化误差是 8 个固定数，均方根由这 8 个数碰巧落在哪里决定；float32 因此读到 161.35 dB，比它的地板高 7.62 dB。1001 与 8000 互素，一个周期铺满整段记录，误差才被平均。这一步做错，阶梯的上半段会整体偏几个 dB 而看不出原因。

### 8.5 那 24 dB 是什么

缺口不在估计器里，也不在文件里，而在引擎的窗上。要看清这一点，先把引擎自身的算术上限量出来。

四精度 FFT 的往返上限用同一段 1 kHz 正弦直接测：把 705 600 点变换到频域再变回来，跳过首尾各 5%，可证零差 666.04 dB；88 200 点 666.16 dB。真实的重采样块是「在 P 点上正变换、补零到 Q、在 Q 点上逆变换」，这条路径在 P = 705 600、Q = 1 411 200 上读 665.26 dB。三个数都在 665 至 666 dB 之间，这就是 binary128 变换链的算术上限，引擎读数 665.52 dB 已经贴着它。

于是 24 dB 的缺口只能来自变换之外的乘法。引擎在变换前后各乘一次窗：文件首尾的渐变（taper_ms，默认 20 ms）与每个块边界的渐变（block_taper_ms，默认 20 ms）。窗是乘法器，它的频谱与信号卷积，旁瓣落进输出带内，读数就被压住。

两个窗的长度与阶数各是一个旋钮。在 16 秒、1 kHz、44.1 kHz 到 88.2 kHz、binary128 上逐个改（表 12）：

@table 12 | 两个渐变的长度与阶数对可证零差的影响，单位 dB。
| 文件渐变 / 块渐变 | 5 阶 | 6 阶 | 7 阶 | 8 阶 | 10 阶 | 12 阶 |
|---|---:|---:|---:|---:|---:|---:|
| 20 ms / 20 ms | 440.21 | 451.22 | 516.49 | 528.42 | 601.67 | 665.28 |
| 20 ms / 600 ms | — | 473.85 | — | — | — | — |
| 600 ms / 600 ms | — | 657.52 | — | — | — | 666.36 |

这张表说明三件事。第一，阶数比长度划算：两个窗都从 20 ms 拉到 600 ms（30 倍）只买到 657.5 dB，而保持 20 ms、把阶数从 5 提到 12 就买到 665.3 dB。长度按 dB/ms 线性买，阶数按旁瓣衰减指数买。第二，长度不能为零：文件渐变取 0 时读数塌到 139.5 dB，因为文件边界成了阶跃；取 1 ms 也只有 290.5 dB。第三，两者不可互换：20 ms 配 12 阶够用，600 ms 配 6 阶不够，说明限制来自旁瓣的高度而不是尾巴的长度。

因此把默认阶数从 5 改成 12（TAPER_SMOOTH12），长度不动。这一改在四精度路径上把读数从 440.21 提到 665.28 dB，+225 dB，机时不变——渐变长度没变，只换了窗多项式。

同一次改动对 float64 路径也是净收益，因为它压的是窗的旁瓣而不是算术：19 kHz 单音从 293.28 dB 升到 306.48 dB，正好落到 float64 的地板 307.2 dB 上；15 kHz 从 306.24 升到 307.09 dB；1 kHz 不变，本来就在地板。高频是受益者，因为窗的旁瓣最容易落在靠近奈奎斯特的地方。

剩下的 24 dB 有明确来源：19 kHz 的读数只有 449.72 dB。高频单音离输出奈奎斯特只有 3 kHz，块渐变的调制边带直接落进带内，加长渐变救不了——块渐变从 100 ms 加到 400 ms，19 kHz 一直是 453.26 dB 不动。所以 1 kHz 处的 665.52 dB 是低频贴着算术上限，而 24 dB 的缺口在宽带信号上会表现为靠近奈奎斯特的那一段先掉下来。这不是调参能消掉的误差，是分块频域方法在高频端的固有代价。

## 9 代价与适用边界

### 9.1 机时是仿射的

任意精度测量的机时不是正比于精度。每个样本付一笔固定的钱（解码、相位求值）和一笔按位计的钱（球算术的累加），因此

@eq 14 | t = passes * N * ( c_{0} + c_{1} p ) ,   c_{0} 单位为微秒/样本/遍

在流式文件分析器上（binary128 输入，211 680 样本，两遍）标定得 c_{0} = 6.34 µs、c_{1} = 0.0131 µs/bit；float64 输入是 3.38 与 0.0133。固定项来自解码与两次三角函数调用，与精度无关，因此低精度时它占大头：46 bit 时占 91%，400 bit 时占 55%。

仿射模型的价值在低精度端。纯正比模型会把 94 bit、1.27×10^{6} 样本的机时说成 4 秒，实测 19 秒——而低精度正是用户最常问的那一端。

三条路径的常数不同（表 13）。流式文件分析器每样本解一次相位；合成直算路径把整数相位基预先算成表，每样本只做一次乘加，因此便宜 2.3 至 2.5 倍，每位的斜率也减半；引擎两遍路径每样本要从 binary128 解码成 Arb，比直算路径又贵 2.9 倍。

### 9.2 边界

这套方法适用的场合有三条限定。

被测件在数字域。它要求被测对象的输出可以被精确读出，因此模拟转换器不适用——ADC 的输出已经是量化的，地板由量化决定，与本文的方法无关。

被测件优于 float64。若被测件的失真在 −120 dBc 量级，float64 的分析链（328 dB）绰绰有余，任意精度只是浪费机时。这套方法的价值出现在被测件好于 300 dB 的场合：数字重采样、数字滤波器、无损编解码的往返。

记录可以离线。式 (14) 的机时是按秒到分钟计的，不是按毫秒。实时监听需要另一套设计，本文不涉及。

三条限定合起来，适用面不宽，但正是这个面里「读数属于谁」这个问题最尖锐：被测件与仪器处在同一量级，任何不区分两者的报告都不可信。

## 10 局限

第一，被测件只有一个。第 8 节是一个四精度重采样引擎、一段 16 秒单声道信号、一个频点；引擎的 249 dB 缺口没有定位到内核，只说「属于引擎」。要把它拆成算术、算法窗与块边界三部分，需要内核级的对照实验，本文没有做。

第二，律是拟合，不是界。26 个点的最大残差 1.86 dB，外推到 3840 bit 时残差涨到 6.79 dB。式 (8) 给出的精度在九例里都够用（余量 +1.58 至 +4.83 dB），但它没有保证，用它规划时要留余量。

第三，保护位平台只测了四个激励精度与两个记录长度。式 (11) 的截距在 0.3 dB 内成立，但 −30.5 dB 的两项分解只在 p_{stim} = 120 与 240 上做过，360 与 480 没有单独拆。两项互补的结论因此是两点之间的插值，不是四点上的验证。

第四，尺子律是拟合。式 (4) 的界松 3.0 dB，尺子律的最大残差 1.5 dB，两者相加决定了判据第 1 步的 20 dB 门槛。这个门槛是工程约定，不是从第一原理推出的。

第五，全部实验都是时不变的单音或多音。频率漂移、相位噪声、非平稳内容（真实音乐）没有处理。真实音乐的块间误差由内容与块边界共同决定，不能把合成单音的 300 dB 外推过去。

第六，多音只做到三阶。五阶、七阶产物的枚举与折叠规则相同，但数量增长很快，本文没有做。

## 11 结论

一个数字音频的读数，只有在同时给出可证下界、收敛中点与尺子地板时才有意义。本文把这三件事做出来，并用它们回答了「读数属于谁」。

答案由三个上限的交集给出。表示的上限是格式地板，五种格式从 92.07 dB 到 689.56 dB，跨度 597.4 dB，同一段理想正弦舍入后逐级落位，误差不超过 0.11 dB。估计器的上限由式 (7) 给出，6.0199 dB/bit、−4.4941 L − 0.0583 L^{2}，长度不免费。文件的上限由式 (11) 给出，6.0199 p_{stim} − 30.5，与记录长度无关。三者取最小值，就是读数；三者与读数的差，就是归属。

泄漏在这套框架里不再是需要对付的干扰。它是单 bin 投影的性质，有闭式 −20 log_{10}|L(2ω_{0})|，49 个读数与它吻合到 0.011 dB；把窗放进模型而不是乘在数据上，泄漏消失，剩下的是舍入。IEEE 1241 的相干采样要求因此是单 bin 估计器的产物，不是测量的必要条件。

把尺子对准一个真实的四精度引擎，得到 665.522 dB 的可证零差。这个数比输出格式的地板低 24.0 dB，比分析器自身地板低 1 614 dB，并已贴住 binary128 变换链自身的算术上限 666 dB。缺口因此可以逐级归位：先把估计器推到饱和（140 bit），再确认格式装得下（689.56 dB），最后把剩下的 24 dB 指到窗上。这正是本文想要的那种陈述——不是一个孤立的数，而是一个数连同它的归属。
